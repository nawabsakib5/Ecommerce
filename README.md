# 🛒 Puddle - E-commerce Marketplace

A full-stack e-commerce marketplace built with Django where users can buy and sell second-hand items.

## 🚀 Features
- User registration & authentication
- Add, edit, delete items with images
- Search items by name or description
- Filter items by category
- Messaging system between buyers and sellers
- User dashboard to manage own items

## 🛠️ Tech Stack
- **Backend:** Python, Django
- **Frontend:** HTML, Tailwind CSS
- **Database:** SQLite
- **Auth:** Django built-in authentication

## ⚙️ Installation
```bash
git clone https://github.com/nawabsakib5/Ecommerce.git
cd Ecommerce
python3 -m venv env
source env/bin/activate
pip install -r puddle/requirements.txt
cd puddle
python manage.py migrate
python manage.py runserver
```

## 📌 Usage
- Register an account
- Post items for sale with images & price
- Search or browse items by category
- Contact sellers via built-in messaging
